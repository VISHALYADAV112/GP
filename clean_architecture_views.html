🎯 Key Insight

The system has a simple star topology:

  • ✓ Core provides master data to all
  • ✓ All revenue & expenditure modules flow to CASHBOOK
  • ✓ CASHBOOK feeds reporting
  • ✓ Side flows: Projects → Operations → Assets
