📋 Integration Rules & Validation

Rule 1: Single Source of Truth

  • Property master: property_assessments
  • Employee master: employees
  • Financial year master: financial_years
  • Gram Panchayat master: gram_panchayats

Rule 2: Mandatory Cashbook Entry

EVERY financial transaction creates cashbook entry:

  • ✓ Receipt → Cashbook (income)
  • ✓ Purchase → Cashbook (expenditure)
  • ✓ Salary → Cashbook (expenditure)
  • ✓ Investment → Cashbook (income/expenditure)

Rule 3: Balance Updates (Atomic Transaction)

When receipt is created for tax bill, ALL must happen in ONE transaction:

  1. Create receipt record
  2. Create cashbook entry
  3. Update tax_demand.balance_amount
  4. Update tax_bill.payment_status
  5. Create audit_log entries

Rule 4: Audit Everything

Every INSERT/UPDATE/DELETE creates audit_log:

  • user_id (who)
  • table_name (where)
  • record_id (which record)
  • old_value (before - JSON)
  • new_value (after - JSON)
  • created_at (when)

✅ Validation Checklist

  • Every receipt creates exactly ONE cashbook entry
  • Cashbook total = Σ receipts - Σ expenditures
  • Tax demand balance = Total - Σ receipts
  • Classified monthly = Σ cashbook entries for month
  • Annual accounts = Σ cashbook entries for year
  • Budget vs actual = Planned vs Cashbook
  • Capital purchases appear in assets
  • All tables have gram_panchayat_id
  • All financial tables have financial_year_id
  • All changes logged in audit_logs
